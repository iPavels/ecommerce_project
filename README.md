# E-commerce Project

## Учебный проект по теме объектно-ориентированного программирования (ООП).

## Реализованный функционал

Созданы классы Product и Category с необходимыми атрибутами.

Для класса Category добавлены атрибуты класса:

category_count — количество категорий,

product_count — количество товаров.
Эти значения обновляются автоматически при создании новых объектов.

## 🔒 Защита метода добавления продуктов в категорию

Метод `add_product()` класса **Category** доработан:

теперь он принимает **только экземпляры класса `Product` или его наследников**.

Если попытаться добавить любой другой объект, будет выброшено исключение `TypeError` с сообщением:

> Можно добавлять только объекты класса Product или его наследников

Это гарантирует, что в категории находятся только корректные товары, а не посторонние данные.

## BaseProduct

Добавлен абстрактный класс **BaseProduct**, который содержит общие свойства и методы для всех продуктов.

Класс **Product** теперь наследуется от него, что обеспечивает единый интерфейс для всех товаров.
